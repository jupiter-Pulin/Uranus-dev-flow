User Asset Snapshot

Feature user-asset-snapshot Owner @pulin Updated 2026-05-10 Draft

1. Requirement Summary

ProblemUsers cannot view a point-in-time snapshot of multi-chain assets, making month-end reconciliation manual.
GoalsDaily snapshot per user across all chains; queryable by date; exportable to CSV.
ScopeEVM chains only (v1). Off-chain and L2 deferred to v2.

3. Technical Solution

3.1 Architecture

flowchart LR Cron[Daily Cron 00:00 UTC] --> Job[SnapshotJob] Job --> Svc[PortfolioService.aggregate] Svc --> Prov[(Alchemy Provider)] Job --> DB[(snapshot collection)] API[GET /snapshots] --> DB

3.2 Data Model

Snapshot {
  userId: string
  date: ISODate          // YYYY-MM-DD, UTC
  chains: ChainBalance[]
  totalUsd: number
  createdAt: Date
}

// index: { userId: 1, date: -1 } unique

3.3 API Design

MethodPathDescription
GET/v1/snapshots?from=&to=Range query, paginated
GET/v1/snapshots/export.csvCSV stream

3.4 Core Logic

  1. Cron triggers SnapshotJob.run() at 00:00 UTC.
  2. Iterate active users in batches of 100.
  3. Aggregate via PortfolioService; persist with idempotent upsert keyed on (userId, date).
  4. Emit metric snapshot.user.success / snapshot.user.fail.
