## Background

雙 Reviewer 架構的測試層：涵蓋 hook 單元測試（emit-review-gate 解析、鎖定機制、stop-guard dual mode、edit invalidation）與整合測試（severity mapping、去重、降級流程）。

## Requirements

| 需求 | 說明 |
|------|------|
| Hook 單元測試 | 測試 3 個 hook 的新增邏輯（W8） |
| 整合測試 | 測試完整 dual-review 流程（W9） |
| 向後相容驗證 | 確認現有測試全數通過 |

## Scope

| Scope | Description |
|-------|-------------|
| In | Hook 單元測試（state update, stop-guard, edit invalidation）、整合測試（severity mapping, 去重, 降級, 完整 flow） |
| Out | 實作修改（見 R1/R2/R3）、E2E 手動驗證 |

## Acceptance Criteria

### AC1: Hook 單元測試（W8）

- [ ] `post-tool-review-state.sh`: emit-review-gate 解析分支正確寫入 `aggregate_gate`
- [ ] `post-tool-review-state.sh`: 鎖定機制 bounded wait + stale recovery
- [ ] `post-tool-review-state.sh`: 鎖定失敗 → fail-closed（`gate=BLOCKED`, `reason=lock_failure`）
- [ ] `stop-guard.sh`: `review_mode=dual` + `aggregate_gate.executed=true` + `gate=READY` → 放行
- [ ] `stop-guard.sh`: `review_mode=dual` + `aggregate_gate.executed=false` → blocked（fail-closed）
- [ ] `stop-guard.sh`: `review_mode` 缺失 → 現有邏輯（向後相容）
- [ ] `stop-guard.sh`: `review_mode=dual` 強制 strict blocking
- [ ] `post-edit-format.sh`: 編輯後 `aggregate_gate.executed=false`、`gate=null`、`reason=null`

### AC2: 整合測試（W9）

- [ ] Severity mapping: toolkit Critical 90 + "security vulnerability" → P0
- [ ] Severity mapping: toolkit Critical 95 (no P0 keyword) → P1
- [ ] Severity mapping: toolkit Important 85 → P2
- [ ] 去重: 同一 file+issue 雙方皆回報 → 合併為 1 項（source=both）
- [ ] 降級: Codex 失敗 + 次要成功 → `source=toolkit-only`
- [ ] 降級: 次要失敗 + Codex 成功 → `source=codex-only`
- [ ] 降級: 都失敗 → `⛔ Blocked` + `⚠️ Need Human`

### AC3: 向後相容

- [ ] 現有所有測試通過（`node --test test/**/*.test.js`）
- [ ] `review_mode` 缺失時行為與修改前完全一致

### Quality Gates

- [ ] Pass `/codex-review-fast`
- [ ] Pass `/precommit`
